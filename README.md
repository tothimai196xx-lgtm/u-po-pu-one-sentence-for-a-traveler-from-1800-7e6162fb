Entry for the [make.fun](https://make.fun) bounty
[One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

`main.ts` writes one sentence of at most 200 characters to
`/output/entry.txt`, explaining the modern internet to someone arriving
from the year 1800 — built only from things a person from 1800 already
knows: a road, a post office, a library, a market, a letter, ink.

Run it with Node 22 or later:

```sh
node main.ts
```
